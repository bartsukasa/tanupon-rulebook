# Discord 変更通知（Apps Script）

スプレッドシートを編集した瞬間に、旧→新の差分をDiscordへ投稿します。
Webルールブックの表示は GitHub Pages（`../index.html`）が担当するので、こちらは通知専用です。

## セットアップ（約5分）
1. 対象スプレッドシートで **拡張機能 → Apps Script** を開く
2. `Code.gs` の内容を貼り付けて保存
3. Discordで通知先チャンネルの **⚙️編集 → 連携サービス → ウェブフック → 新規** を作り、**URLをコピー**
4. Apps Script の **⚙️プロジェクトの設定 → スクリプト プロパティ** に
   - キー: `DISCORD_WEBHOOK_URL`
   - 値: コピーしたWebhook URL
   を登録（※コードやチャットに貼らないこと）
5. 関数 `testDiscord` を実行 → 権限承認 → Discordにテスト投稿が来ればOK
6. 関数 `setupTrigger` を実行 → 「編集時トリガー」が登録される

以降、監視対象タブ（`WATCH_TABS`）のセルを編集するたびに自動通知されます。

## 補足
- 旧→新は **1マスずつの編集** で最も正確に出ます。複数マスの一括貼り付けは新しい内容のみ通知されます。
- 編集者名は組織アカウント等の条件を満たす場合のみ表示（個人Gmailでは空欄になることがあります）。
- 通知対象タブを変えたいときは `WATCH_TABS` を編集してください。
